# Verbier WhatsApp Bot

Verbier webcam and weather updates delivered through WAHA's GOWS engine.

The bot sends updates at **08:00 and 12:00 Europe/Zurich** and responds to commands such as `!!` and `!snow weather`. Each report combines Le Carrefour, Les Attelas, Savoleyres and the Hôtel W/Médran village camera, plus MeteoSwiss observations from Les Attelas and Montagnier.

Start with the [Quick Start](quickstart.md), then follow [Docker deployment and pairing](deployment/docker.md). Existing installations should read [NAS migration](deployment/nas.md) before upgrading from whatsapp-web.js.
